## Severity Classification Schedule
*   **Material:** Directly alters a fundamental architectural conclusion, security risk level, design pattern grading, or execution roadmap sequence.
*   **Moderate:** Refines technical explanations, harmonizes divergent effort estimates, or removes unsupported numerical metrics (e.g., unmeasured coverage or WCAG claims).
*   **Editorial:** Corrects minor file path typos, formatting inconsistencies, or single-digit line count adjustments.
