## 2. Non-Negotiable Product Scope & Truthful Demonstration Boundaries
This refactoring effort adheres strictly to the corrected audit conclusions and explicit product scope boundaries:
1.  **Workforce Intelligence Platform:** RoarCast serves as an interactive workforce-intelligence and student-readiness platform. It does not replace schools, municipal PESO offices, TESDA, or job matching job-board portals.
2.  **User Experiences:** Current platform experiences focus strictly on Student journeys and shared Admin analytical environments (viewed through Academe/PESO filters). No standalone employer portal will be engineered; employers function primarily as regional demand-signal sources.
3.  **Truthful Readiness Metrics & Sample Data:** All labor figures, active student counts, readiness calculations, partner logos, and institutional statistics represent demo sample prototypes unless generated by validated integrations. Readiness scores are preparatory diagnostic tools, never hiring decision evaluations or employment guarantees.
4.  **No Speculative Enterprise Architecture:** We explicitly bypass creating speculative enterprise microservices, blockchain functionality, accredited qualification issuing claims, or production DBMS integrations during this demonstration stabilization phase.
