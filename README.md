# RoarCast - Powering the Triple Helix of Santa Rosa

**FROSTBYTE: YOUTH WEEK HACKATHON 2026** - "Break the Ice. Build the Future."

## 🚀 About The Project

RoarCast is a platform designed to solve the timing issue of youth underemployment and skills mismatch in Santa Rosa, Laguna. By establishing a real-time, autonomous intelligence-sharing infrastructure, RoarCast translates industry demand from Santa Rosa's PEZA-registered locators into academic supply, bridging the gap between students and employers before graduation. 

### Core Features

*   **Data Engine:** Automated system pulling job postings and skill requirements across Santa Rosa's PEZA zones.
*   **Micro-Audits:** 60-second assessments for students to cross-check their skills against real-world DOLE/TESDA regional forecasts and industry requirements.
*   **Co-Op Upskilling Squads:** Peer groups that allow students to close their skills gap together.
*   **Verifiable Credentials:** Credentials built on W3C Verifiable Credentials and 1EdTech Open Badges standards.
*   **Admin Dashboard:** Aggregated, anonymized data filters for Academe (curriculum planning) and LGU/PESO (Special Education Fund allocation).

## 📂 Project Structure

This repository is currently in the **Proof of Concept (PoC)** phase. The foundational directory structure has been created to support future development:

*   `frontend/` - Will contain the student-facing React/Next.js application and UI.
*   `backend/` - Will handle the core logic and Supabase/Firebase configurations.
*   `data-engine/` - Will contain scripts for autonomous job-post ingestion and parsing.
*   `research/` - For storing local context, news reports, SDG/CYP alignment, and citations.
*   `docs/` - For project briefs, pitch narratives, and requirements (e.g., `FOUR_PLUS_ONE_Elimination_Brief.pdf`).
